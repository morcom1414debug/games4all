# กฎเหล็กข้อ 10 — Treasure

มี 8 ช่อง

เมื่อผู้เล่นลง:

> ได้ Holy Armor 1 ชิ้น

ไม่มีเหรียญ

เกราะสูงสุด:

> 3 ชิ้น

หากมี 3 ชิ้นแล้ว ให้คงไว้ 3 ชิ้น

ห้ามเกิด Item มากกว่า 3

ต้องมี Visual Effect เช่น:

* เปิดกล่อง
* Sparkle
* Glow

และเสียงตามระบบ Audio ของเกม

# กฎเหล็กข้อ 11 — Holy Armor

เกราะใช้ป้องกัน Bad Event ที่ป้องกันได้

เมื่อมีสิทธิ์ใช้:

แสดง UI ที่เข้าถึงได้ด้วย Keyboard และ VoiceOver:

> ใช้เกราะศักดิ์สิทธิ์ป้องกันหรือไม่?

ปุ่ม:

> ใช้เกราะ

และ:

> ไม่ใช้

หากใช้:

* Armor -1
* ยกเลิกผลเสีย
* ไปยัง State ถัดไปอย่างถูกต้อง

หากไม่ใช้:

* ดำเนิน Event ปกติ

ห้ามใช้เกราะกับการทอยลูกเต๋าปกติ

# กฎเหล็กข้อ 13 — Trap

มี 7 ช่อง

สุ่มผล:

> -2 ถึง -6

สามารถป้องกันด้วย Holy Armor

# กฎเหล็กข้อ 14 — Water

มี 5 ช่อง

สุ่มผล:

> -1 ถึง -5

แสดง Visual/Audio ให้รู้สึกเหมือนกระแสน้ำพัดตัวละคร

ต้องไม่ทำให้ตัวละครออกนอกกระดาน

# กฎเหล็กข้อ 15 — Ghost

มี 5 ช่อง

Ghost ต้องเป็นเหตุการณ์เชิงลบที่ไม่ใช่การถอยหลังแบบ Trap/Water

สามารถใช้ผลเช่น:

> เสียเทิร์นถัดไป

อย่างน้อยผลเสียบางประเภทต้องป้องกันด้วย Holy Armor

ต้องมี Ghost Animation และ Sound

ห้ามใช้ Ghost เป็นเหตุให้เกิด Loop ไม่รู้จบ

---

# กฎเหล็กข้อ 16 — Warp

มี 4 ช่อง

เมื่อผู้เล่นลง:

สุ่มเป็น:

### Lucky Warp

เดินหน้า:

> 10–20 ช่อง

หรือ

### Unlucky Warp

ถอยหลัง:

> 10–20 ช่อง

Unlucky Warp สามารถป้องกันด้วย Holy Armor

ทุกค่าต้องมาจาก Host

# กฎเหล็กข้อ 20 — Special Chain

ห้ามสร้าง Recursive Special Chain

**Trap ต้องไม่ทำงานทันที**

# กฎเหล็กข้อ 28 — Focus

ต้องย้าย Focus ไป Heading หรือ Element ที่เหมาะสม

เช่น:

Lobby → Game

Game → Result

เมื่อเปิด Modal เช่น Armor หรือ Door:

* Focus เข้า Modal
* Keyboard ใช้งานได้
* Screen Reader รู้ว่าต้องเลือกอะไร
* หลังปิด Modal ให้คืน Focus ไปยัง Element ที่เหมาะสม

# กฎเหล็กข้อ 29 — VoiceOver

ต้องทดสอบเป็นพิเศษบน iOS Safari + VoiceOver

ห้ามออกแบบ Interaction ที่อาศัยเพียง:

* mouse hover
* pointer event อย่างเดียว
* click ที่เกิดจาก visual element แต่ไม่ใช่ปุ่ม
* DOM ที่ถูกซ่อนด้วยวิธีที่ VoiceOver มองไม่เห็น

ทุก Action สำคัญต้องเป็น `<button>` หรือ Control ที่เข้าถึงได้
