งาน: ปรับพื้นที่แสดงผลของเกม Escape Tower หลังลบแถบคำอธิบายเหนือกระดาน 20 ห้องแล้ว

**เป้าหมาย**

ใช้พื้นที่ที่ได้คืนมาจัดสัดส่วนกระดาน 20 ห้องและพื้นที่ข้อความเหตุการณ์ให้เหมาะสม กระดานควรขยับขึ้นและมีพื้นที่แสดงผลชัดเจนขึ้น ขณะเดียวกันข้อความเหตุการณ์ต้องอ่านง่าย ไม่ถูกตัดหรือเบียดจนเกินไป ให้จัดสัดส่วนทั้งสองส่วนอย่างสมดุล และรองรับหน้าจอขนาดเล็กตามเดิม

**กฎเหล็กที่ต้องปฏิบัติตามอย่างเคร่งครัด**

1. แก้ไขเฉพาะไฟล์ `escape_tower.css` เท่านั้น
2. ใช้ `escape_tower.html` ที่แนบมาเพื่ออ้างอิงโครงสร้างเท่านั้น ห้ามแก้ไข HTML หรือ JavaScript
3. ปรับเฉพาะกฎ CSS ที่จำเป็นต่อพื้นที่ ตำแหน่ง ขนาด และระยะห่างของกระดานกับข้อความเหตุการณ์
4. ตรวจสอบ Media Queries และการแสดงผลบนหน้าจอขนาดเล็ก เพื่อไม่ให้กระดานหรือข้อความเหตุการณ์ถูกตัดหรือซ้อนทับ
5. ห้ามเปลี่ยนสี รูปแบบ ปุ่ม ไอคอน แอนิเมชัน หรือองค์ประกอบอื่นที่ไม่เกี่ยวข้อง
6. ห้ามเปลี่ยนกติกาเกม ระบบเสียง Firebase ระบบหลายคน ระบบบอท เวลาเล่น หรือพฤติกรรมของเกม
7. ห้ามแก้ไขการเข้าถึงด้วย Screen Reader รวมถึง ARIA การประกาศสถานะ และการจัดการโฟกัส
8. ห้ามรีแฟกเตอร์ ห้ามลบกฎ CSS ที่ไม่เกี่ยวข้อง ห้ามจัดระเบียบไฟล์ใหม่ และห้ามแก้ส่วนอื่นนอกขอบเขต
9. หากกฎ CSS เดิมมีผลต่อองค์ประกอบอื่น ให้รักษาพฤติกรรมเดิมขององค์ประกอบเหล่านั้นไว้ ห้ามแก้แบบเหมารวมจนเกิดผลข้างเคียง

**ข้อกำหนดการส่งงาน**

- ส่งกลับ `escape_tower.css` ฉบับเต็มตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย
- ห้ามตัดทอน ห้ามใช้ `...` แทนโค้ด ห้ามส่งเฉพาะส่วนที่แก้ และห้ามส่งเป็น Diff
- ห้ามละเว้นกฎ CSS เดิมส่วนใดที่ไม่เกี่ยวข้องกับงาน
- ก่อนส่ง ให้ตรวจสอบว่าแก้เฉพาะ CSS ที่จำเป็นและไม่มีการเปลี่ยนแปลงนอกขอบเขต
