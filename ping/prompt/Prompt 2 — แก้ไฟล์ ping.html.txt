Prompt 2 — แก้ไฟล์ ping.html

ให้แก้ไขเฉพาะไฟล์ ping.html ที่แนบมาเท่านั้น เพื่อจัดการการแสดงปุ่มในหน้าสร้างห้อง รายการห้อง และการแข่งขันออนไลน์แบบ 1 ต่อ 1 ตามข้อกำหนดด้านล่าง

กฎเหล็ก:
1. แก้เฉพาะ HTML และโค้ดภายใน ping.html เท่าที่จำเป็นต่อข้อกำหนดนี้ ห้ามแก้ไฟล์อื่น
2. ห้ามเขียนหน้าเว็บใหม่ ห้ามรื้อโครงสร้าง ห้าม refactor และห้ามแก้ส่วนที่ทำงานถูกต้องอยู่แล้ว
3. ในหน้าสร้างห้องและหน้ารายการห้อง ต้องนำปุ่ม “ย้อนกลับสู่หน้าแรก” ออกจากบริบทดังกล่าวตามที่กำหนด โดยไม่ลบหรือทำให้ปุ่มย้อนกลับที่ใช้ในหน้าอื่นเสียหาย
4. เมื่อ Host สร้างห้องออนไลน์สำเร็จ หรือ Client เข้าร่วมห้องสำเร็จแล้ว ในห้องแข่งขันออนไลน์ 1 ต่อ 1 ต้องไม่แสดงปุ่ม “ออกจากห้องแข่งขันออนไลน์” และ “ย้อนกลับสู่หน้าแรก” ทั้งสองปุ่ม
5. ซ่อนหรือนำปุ่มออกเฉพาะในสถานะและบริบทที่ระบุเท่านั้น ต้องไม่ทำให้การแสดงปุ่มในหน้าหรือโหมดอื่นเปลี่ยนไปโดยไม่จำเป็น
6. รักษา SoundEngine และการกำหนดไฟล์เสียงเดิม รวมถึง miss: audio/3.mp3 และ miss4: audio/4.mp3 ห้ามสร้างระบบเสียงซ้ำหรือเปลี่ยนชื่อและความหมายของเสียง
7. คง id, class, ชื่อฟังก์ชัน, event handler, onclick และจุดเชื่อมต่อกับ OnlineMatchController เดิมไว้ ห้ามเปลี่ยนชื่อหรือลบโดยไม่จำเป็น
8. ห้ามเปลี่ยนระบบ Firebase, ระบบล็อกอิน, กติกาเกม, การแข่งขัน, คะแนน หรือส่วนอื่นที่ไม่เกี่ยวข้อง
9. ต้องรองรับหน้าจอมือถือและเดสก์ท็อป โดยไม่ทำให้การจัดวางหรือการเข้าถึงส่วนอื่นเสียหาย

การส่งมอบ:
- ส่งคืนไฟล์ ping.html ฉบับเต็มตั้งแต่บรรทัดแรกถึงบรรทัดสุดท้าย
- ห้ามตัดทอน ห้ามใช้ ... ห้ามส่งเฉพาะส่วนที่แก้ ห้ามส่ง diff หรือ pseudocode
- ห้ามละเว้น HTML, CSS, JavaScript หรือโค้ดเดิมส่วนใดในไฟล์
- ห้ามสร้างไฟล์ใหม่หรือเปลี่ยนชื่อไฟล์
- ตรวจสอบการเปิดปิดแท็ก การเชื่อมต่อกับ ping-online.js และการทำงานของปุ่มก่อนส่ง
