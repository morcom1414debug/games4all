Prompt 1 — แก้ไฟล์ ping-online.js

ให้แก้ไขเฉพาะไฟล์ ping-online.js ที่แนบมาเท่านั้น โดยมีเป้าหมายเพื่อแก้ปัญหาการประสานการเล่นเสียง 3.mp3 และ 4.mp3 ระหว่าง Host และ Client ในการแข่งขันออนไลน์แบบ 1 ต่อ 1 และจัดการการแสดงปุ่มตามข้อกำหนดด้านล่าง

กฎเหล็ก:
1. แก้เฉพาะปัญหาที่ระบุ ห้ามแก้ระบบเกมส่วนอื่นที่ทำงานถูกต้องอยู่แล้ว
2. ห้ามเขียนไฟล์ใหม่แทนไฟล์เดิม ห้ามรื้อโครงสร้าง ห้าม refactor และห้ามเปลี่ยนระบบโดยไม่จำเป็น
3. ต้องตรวจสอบโค้ดเดิมก่อนแก้ โดยเฉพาะระบบ Firebase, การสร้างห้อง, การเข้าร่วมห้อง, การซิงก์สถานะการแข่งขัน, การจัดการ Host/Client และระบบเสียงเดิม
4. เสียง 3.mp3 และ 4.mp3 ต้องถูกกระตุ้นจากเหตุการณ์เดียวกันสำหรับทั้ง Host และ Client โดยใช้ข้อมูลเหตุการณ์ร่วมที่เชื่อถือได้ ไม่ใช่ให้แต่ละฝั่งตัดสินใจเล่นเสียงแยกกันจนเกิดเสียงไม่ตรงกันหรือเล่นซ้ำ
5. ป้องกันการเล่นเสียงซ้ำจากการรับข้อมูล Firebase ซ้ำหรือ listener ทำงานซ้ำ และคำนึงถึงการเชื่อมต่อช้า การโหลดเสียง และข้อจำกัดการเล่นเสียงของเบราว์เซอร์ โดยห้ามกล่าวอ้างว่าสามารถซิงก์ตรงกันระดับมิลลิวินาทีได้หากระบบไม่รองรับ
6. รักษาพฤติกรรมและไฟล์เสียงเดิม ห้ามเปลี่ยนชื่อไฟล์หรือเปลี่ยนความหมายของเสียง 3.mp3 และ 4.mp3
7. ในการแข่งขันออนไลน์ 1 ต่อ 1 เมื่อผู้เล่นสร้างห้องหรือเข้าร่วมห้องแล้ว ต้องไม่แสดงปุ่ม “ออกจากห้องแข่งขันออนไลน์” และ “ย้อนกลับสู่หน้าแรก” ตามข้อกำหนด ห้ามทำให้ระบบออกจากห้อง การจบแมตช์ หรือการจัดการสถานะห้องเสียหาย
8. คงชื่อ function, id, class, event handler และการเชื่อมต่อเดิมทั้งหมด เว้นแต่จำเป็นโดยตรงต่อการแก้ปัญหา
9. ห้ามแก้ ping.html, auth.js หรือไฟล์อื่นใด
10. ต้องตรวจสอบไม่ให้เกิดข้อผิดพลาด JavaScript และไม่ให้ Host/Client เล่นเสียงซ้ำหรือพลาดเหตุการณ์จากการประมวลผลข้อมูลเดียวกันหลายครั้ง

การส่งมอบ:
- ส่งคืนไฟล์ ping-online.js ฉบับเต็มตั้งแต่บรรทัดแรกถึงบรรทัดสุดท้าย
- ห้ามตัดทอน ห้ามใช้เครื่องหมาย ... ห้ามส่งเฉพาะส่วนที่แก้ ห้ามส่ง diff หรือ pseudocode
- ห้ามละเว้นฟังก์ชันหรือโค้ดเดิมส่วนใด แม้ไม่ได้แก้ไข
- ห้ามสร้างไฟล์ใหม่หรือเปลี่ยนชื่อไฟล์
- ก่อนส่ง ให้ตรวจสอบว่าไฟล์ครบถ้วนและโค้ดส่วนที่ไม่เกี่ยวข้องยังคงเดิมให้มากที่สุด
