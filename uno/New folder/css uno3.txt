# วัตถุประสงค์

พบปัญหาการแสดงผลการ์ดในมือของตัวละครประจำเครื่อง ระหว่างเล่นเกมบน Smart Phone แนวตั้ง โดยทดสอบพบชัดเจนบน iPhone 15 Pro

ปัญหาที่พบคือ เมื่อผู้เล่นมีการ์ดหลายใบจนแสดงหลายแถว:

* การ์ดในมือแสดงเป็นหลายแถวตามเดิม
* แต่การ์ดใบขวาสุดของแต่ละแถวเห็นไม่ครบ
* ขอบด้านขวาของการ์ดถูกตัด
* ตัวเลขหรือรายละเอียดบริเวณขอบการ์ดด้านขวาถูกตัดออกบางส่วน
* พบทั้งแถวแรก
* แถวที่สองก็มีปัญหาเดียวกัน
* หากมีแถวที่สามหรือมากกว่านั้น ก็ต้องไม่เกิดปัญหาเช่นเดียวกัน

# สิ่งที่ต้องแก้ไข

ปรับเฉพาะ CSS ที่เกี่ยวข้องกับ Layout และการแสดงผลของพื้นที่การ์ดในมือบนหน้าจอ Smart Phone แนวตั้งเท่านั้น

ต้องทำให้:

1. การ์ดทุกใบแสดงครบทั้งใบ
2. การ์ดใบขวาสุดของทุกแถวต้องไม่ถูกตัด
3. ขอบการ์ด ตัวเลข สัญลักษณ์ และรายละเอียดบนการ์ดต้องมองเห็นครบ
4. ทุกแถวต้องมีพฤติกรรมเหมือนกัน ไม่ใช่แก้เฉพาะแถวแรก
5. ต้องรองรับกรณีมีการ์ดหลายแถว
6. ต้องไม่เกิด horizontal overflow หรือการ์ดล้นออกนอกพื้นที่โดยไม่จำเป็น
7. ต้องคงรูปแบบการจัดเรียงการ์ดเดิมให้มากที่สุด
8. แก้ปัญหาด้วยการปรับ CSS Layout ที่เป็นสาเหตุจริงเท่านั้น

สามารถปรับเฉพาะ CSS ที่จำเป็นจริง ๆ เช่น:

* Grid sizing
* ความสัมพันธ์ระหว่าง column กับ container
* `minmax(0, ...)`
* `min-width`
* `max-width`
* `box-sizing`
* gap
* padding
* overflow

แต่ให้เลือกแก้เท่าที่จำเป็นจริง ๆ เพื่อแก้ปัญหานี้เท่านั้น

# หลักการทำงานที่ต้องปฏิบัติ

ก่อนแก้ไข:

1. ตรวจสอบ CSS เดิมทั้งหมดที่เกี่ยวข้องกับ `my-cards-container` และองค์ประกอบการ์ดในมือ
2. วิเคราะห์หาสาเหตุจริงว่าทำไมการ์ดใบขวาสุดจึงถูกตัดบน Smart Phone แนวตั้ง
3. แก้เฉพาะ CSS ที่เป็นสาเหตุ
4. ห้าม Refactor CSS ส่วนอื่น
5. ห้าม Cleanup โค้ดที่ไม่เกี่ยวข้อง
6. ห้ามเปลี่ยนชื่อ class หรือ selector
7. ห้ามเขียน CSS ใหม่ทั้งระบบ
8. ห้ามเปลี่ยนพฤติกรรมเดิมบน Desktop หรืออุปกรณ์อื่นโดยไม่จำเป็น
