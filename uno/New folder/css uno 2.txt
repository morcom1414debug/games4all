งานนี้ให้แก้ไขเฉพาะไฟล์ JavaScript เดิมที่มีระบบ Audio และควบคุมการเล่นเสียง `abc.mp3` เท่านั้น

# วัตถุประสงค์

ปัจจุบัน Logic ของเกมกำหนดไว้ว่า:

* `turn.mp3` เล่นตามระบบเดิม
* `abc.mp3` เป็นเสียงเฉพาะเครื่องของผู้เล่นที่ถึงรอบของตัวเองเท่านั้น
* Bot ไม่เกี่ยวข้องกับ `abc.mp3`
* ห้ามให้ `abc.mp3` เล่นเพราะเป็นรอบของ Bot
* ห้ามให้เครื่องผู้เล่นคนอื่นเล่น `abc.mp3` แทนเจ้าของรอบ

Logic เดิมนี้ถูกต้องและต้องคงไว้ทั้งหมด

ปัญหาที่ต้องการปรับมีเพียงเรื่องเดียว:

หลังจาก `turn.mp3` จบลงแล้ว `abc.mp3` เล่นติดกันเร็วเกินไป ทำให้เสียงรู้สึกทับกันหรือกระชั้นเกินไป

# สิ่งที่ต้องแก้ไข

เพิ่มระยะเวลาหน่วง **1 วินาที**

โดยให้ลำดับเป็น:

1. `turn.mp3` เล่นตาม Logic เดิม
2. รอจน `turn.mp3` จบตามปกติ
3. หน่วงเวลาเพิ่มอีก 1 วินาที
4. ตรวจสอบอีกครั้งว่ารอบปัจจุบันยังเป็นของผู้เล่นเครื่องนั้นจริง
5. ต้องตรวจสอบว่าไม่ใช่ Bot
6. หากยังเป็นรอบของผู้เล่นเครื่องนั้นจริง จึงเล่น `abc.mp3`

# หลักการแก้ไข

ก่อนแก้:

1. ตรวจสอบ Logic เดิมของ `turnAudioEnqueued`
2. ตรวจสอบ Logic เดิมของ `pendingABC`
3. ตรวจสอบเงื่อนไขเดิมที่ป้องกัน Bot
4. รักษา Logic เดิมทั้งหมด
5. เพิ่มเฉพาะ Delay 1000 milliseconds ในตำแหน่งที่เหมาะสมที่สุด
