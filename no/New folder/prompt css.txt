# ส่วนที่ 1 : เหรียญบนไพ่เมื่อมีการเพิ่มเหรียญ

ปรับหรือเพิ่ม Animation สำหรับ

* `.table-coins`
* `#table-coins-display`
* Class Trigger ที่ JavaScript เพิ่มให้

เมื่อเหรียญเพิ่มขึ้น

ให้เกิด

* Scale สูงสุดประมาณ 160%
* Glow สีทอง
* ประกายแวววาวสั้น ๆ
* Bounce เบา ๆ
* กลับสู่สภาพปกติภายในประมาณ 0.3 ถึง 0.5 วินาที

ห้ามใช้ Flash รุนแรง

ห้ามใช้แสงกระพริบต่อเนื่อง

Animation ต้องเกิดครั้งเดียวต่อ Event

# ส่วนที่ 2 : ไพ่กลางโต๊ะตอบสนองต่อเหรียญ

เมื่อมีการจ่ายเหรียญ

ให้ไพ่

1. เอียงซ้ายเล็กน้อย
2. เอียงขวาเล็กน้อย
3. กลับมาตรง

ให้ความรู้สึกเหมือนถูกเหรียญกระแทก

Animation ต้องสั้น

ประมาณ 0.3 ถึง 0.5 วินาที

ต้องไม่ใช้ Animation วนซ้ำ

# ส่วนที่ 3 : ไพ่ที่เคลื่อนจากกองไปกลางโต๊ะ

ปรับ `.visual-fly-card` หรือเพิ่ม Class เฉพาะสำหรับ Animation เปิดไพ่ใหม่

Visual ต้องรองรับ

* เริ่มจากตำแหน่งกองไพ่
* เคลื่อนที่ไปยังไพ่กลางโต๊ะ
* มีมิติการพลิกหน้าไพ่
* เมื่อถึงตำแหน่งปลายทางมี Bounce เล็กน้อย
* ดูเป็นธรรมชาติ

ระยะเวลารวมประมาณ 0.6 ถึง 0.8 วินาที

ต้องใช้ CSS ที่ลื่นไหล เช่น

* `transform`
* `opacity`

หลีกเลี่ยง Animation ที่ทำให้เกิด Layout Reflow โดยไม่จำเป็น

Animation ต้องไม่บล็อกการเล่น

# ส่วนที่ 4 : ไพ่ที่ถูกผู้เล่นรับ

เพิ่มหรือปรับ CSS สำหรับ Visual Flying Card

# ส่วนที่ 5 : เหรียญบินไปหาผู้เล่น

ปรับ `.visual-fly-coin` หรือเพิ่ม Class สำหรับเหรียญที่บิน

# ส่วนที่ 7 : ไพ่ใหม่ในมือผู้เล่น

เพิ่ม CSS Animation สำหรับ `.mini-card`

โดยใช้ Class Trigger เฉพาะกับไพ่ใหม่

ไพ่ใหม่ต้อง

* เลื่อนเข้ามา
* Scale ขึ้นเล็กน้อย
* Bounce เบา ๆ
* เข้าสู่ตำแหน่งปกติ

ระยะเวลาประมาณ 0.4 ถึง 0.6 วินาที

ไพ่เดิมต้องไม่กระโดดหรือเคลื่อนแบบรุนแรง

การจัด Grid เดิมของ `.my-cards-grid` ต้องคงไว้

ห้ามเปลี่ยนจำนวนคอลัมน์หรือ Logic การจัดไพ่

หาก CSS สามารถทำให้การเปลี่ยนตำแหน่งของไพ่เดิมดูนุ่มนวลโดยไม่เปลี่ยน DOM หรือ Layout หลัก สามารถทำได้ แต่ต้องไม่กระทบ Accessibility หรือการทำงานเดิม

# คุณภาพ Animation

Animation ทุกตัวต้อง

* ลื่นไหล
* ใช้ `transform` และ `opacity` เป็นหลัก
* ไม่กระตุก
* ไม่ใช้ Flash รุนแรง
* ไม่ใช้แสงวูบวาบต่อเนื่อง
* ไม่ใช้ Particle เต็มหน้าจอ
* ไม่ใช้ Infinite Animation สำหรับ Effect ใหม่
* ไม่รบกวนการเล่น
* ไม่บังปุ่มควบคุม
* Element Visual ชั่วคราวต้องมี `pointer-events: none`

ทุก Effect ต้องเกิดเฉพาะเมื่อมี Event สำคัญเท่านั้น

เป้าหมายคือ

เพิ่มความเข้าใจสถานการณ์ของเกมจากการมองเห็น

ทำให้ผู้เล่นรู้ทันทีว่า

* มีคนจ่ายเหรียญ
* ไพ่ใหม่ถูกเปิดจากกอง
* ผู้เล่นรับไพ่
* ผู้เล่นได้รับเหรียญ
* จำนวนเหรียญของตัวเองเพิ่ม
* มีไพ่ใบใหม่เข้ามาในมือ

# prefers-reduced-motion สำคัญมาก

ในไฟล์เดิมมีระบบ

`@media (prefers-reduced-motion: reduce)`

อยู่แล้ว

ต้องรักษาไว้และขยายให้ครอบคลุม Animation ใหม่ทั้งหมด

เมื่อผู้ใช้เปิด Reduced Motion

Animation ใหม่ทั้งหมดต้องถูกปิด

รวมถึง

* Coin Pulse
* Coin Glow Animation
* Coin Sparkle
* Table Card Shake
* Flying Card Animation
* Flying Coin Animation
* HUD Coin Gain Animation
* New Hand Card Animation

ห้ามลบหรือทำลาย Reduced Motion เดิม

หากมี Class Animation ใหม่ ต้องเพิ่มเข้าไปใน Reduced Motion อย่างครบถ้วน

* `.mini-card`
* `.visual-fly-coin`
* `.visual-fly-card`
* `.pulse-anim`
* `.pop-anim`
* `@media (prefers-reduced-motion: reduce)`

ห้ามลบ Style เดิมที่ไม่เกี่ยวข้อง

ห้าม Refactor CSS ทั้งไฟล์

ห้ามเปลี่ยนชื่อ Class เดิมโดยไม่จำเป็น

ให้เพิ่ม Class ใหม่เฉพาะสำหรับ Animation ใหม่เมื่อจำเป็น

ต้องระวังไม่ให้ Animation ใหม่ชนกับ

* `transform` เดิม
* `transition` เดิม
* `.active-turn`
* `.visual-avatar.is-turn`

ส่งกลับเป็นไฟล์ `style(4).css` ฉบับเต็มทั้งหมด

ห้ามส่งเฉพาะ snippet

ห้ามตัด CSS ส่วนอื่นออก
