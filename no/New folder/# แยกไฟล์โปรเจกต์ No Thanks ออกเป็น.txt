# แยกไฟล์โปรเจกต์ No Thanks ออกเป็น HTML, CSS และ JavaScript

ให้นำไฟล์ no.html ที่แนบมา แยกออกเป็น 3 ไฟล์ดังนี้

* no.html
* style.css
* game.js

ข้อกำหนดสำคัญ

1. ต้องรักษาการทำงานเดิมของเกมทั้งหมด 100%
2. ห้ามแก้ไข Logic เกมแม้แต่บรรทัดเดียว
3. ห้ามเพิ่ม ฟีเจอร์ ลบ ฟีเจอร์ หรือปรับพฤติกรรมใด ๆ ของเกม
4. ห้ามเปลี่ยนชื่อ id, class, function, variable, constant, event listener หรือโครงสร้างข้อมูลใด ๆ
5. ห้ามเปลี่ยน Firebase configuration
6. ห้ามเปลี่ยน PeerJS configuration
7. ห้ามเปลี่ยนลำดับการทำงานของ JavaScript
8. ห้ามลบ comment เดิม
9. ห้ามแก้ไขข้อความ ภาษา เสียง รูปแบบ aria-label aria-live role tabindex หรือ accessibility ใด ๆ
10. ต้องให้ผลลัพธ์หลังแยกไฟล์ทำงานเหมือนไฟล์เดิมทุกประการ

วิธีแยกไฟล์

1. ย้าย CSS ทั้งหมดที่อยู่ภายในแท็ก <style> ไปไว้ในไฟล์ style.css
2. ลบแท็ก <style> เดิมออกจาก HTML
3. เพิ่มในส่วน head

<link rel="stylesheet" href="style.css">

4. ย้าย JavaScript ทั้งหมดที่อยู่ภายใน

<script type="module">
...
</script>

ไปไว้ในไฟล์ game.js

5. ลบ script เดิมออกจาก HTML
6. เพิ่มก่อนปิด </body>

<script type="module" src="game.js"></script>

7. ต้องคง import Firebase แบบ ES Module ไว้ใน game.js ตามเดิม
8. ต้องคงลำดับของโค้ด JavaScript เดิมทั้งหมด
9. ต้องไม่ย้ายโค้ดข้ามลำดับเดิม
10. ต้องไม่รวม ลดทอน หรือ Refactor โค้ดใด ๆ

ผลลัพธ์ที่ต้องส่งกลับ

1. no.html ฉบับเต็มหลังแยกไฟล์
2. style.css ฉบับเต็ม
3. game.js ฉบับเต็ม
4. สรุปว่ามีการย้ายโค้ดส่วนใดบ้าง

ตรวจสอบก่อนส่งงาน

* เกมสร้างห้องได้
* เข้าห้องได้
* PeerJS ทำงานได้
* Firebase ทำงานได้
* เลือกตัวละครได้
* เพิ่มบอทได้
* ลดบอทได้
* เริ่มเกมได้
* เล่นเกมได้
* Timer ทำงานได้
* เสียงทำงานได้
* Keyboard Shortcut ทำงานได้
* aria-live ทำงานได้
* aria-label ทำงานได้
* View Player Status ทำงานได้
* หน้าสรุปผลทำงานได้
* ไม่มี error ใน Console
* พฤติกรรมทุกอย่างเหมือนต้นฉบับ 100%
