ปรับที่ไฟล์ style.css ต่อได้เลย เอาไฟล์เดียวพอ***
ปรับแก้ที่ไฟล์ style.css และไฟล์ no.html
แต่ฉันส่ง game.js มาประกอบกับปรับให้ด้วย
ให้ตรวจสอบและปรับแก้เฉพาะส่วน Visual Layout / Responsive Layout ของหน้าเล่นเกมเท่านั้น ตามรายละเอียดด้านล่าง โดยต้องรักษากฎเหล็กทุกข้ออย่างเคร่งครัด

# กฎเหล็กสูงสุด ห้ามละเมิดเด็ดขาด

1. ห้ามแก้ไข Logic การเล่นเกมทั้งหมดโดยเด็ดขาด
2. ห้ามเปลี่ยนกติกาเกม
3. ห้ามเปลี่ยน Flow การเล่นเกม
4. ห้ามเปลี่ยนระบบ Turn
5. ห้ามเปลี่ยนระบบผู้เล่นหรือบอท
6. ห้ามเปลี่ยน Firebase
7. ห้ามเปลี่ยนระบบ Multiplayer
8. ห้ามเปลี่ยนระบบเสียง หรือจังหวะการเล่นเสียง
9. ห้ามเปลี่ยนระบบ Screen Reader
10. ห้ามเปลี่ยน aria-live หรือข้อความประกาศเดิม เว้นแต่จำเป็นอย่างยิ่งจากการจัดโครงสร้าง Visual และต้องไม่ทำให้ Accessibility เดิมเสีย
11. ห้ามเปลี่ยน Keyboard Shortcut
12. ห้ามเปลี่ยน Animation Logic เดิม
13. ห้ามลบ Function, Event Listener, ID, Class หรือ Element เดิมที่ JavaScript ใช้งาน
14. ห้ามเปลี่ยนชื่อ ID เดิมทั้งหมด
15. ต้องคงการทำงานเดิม 100%
16. แก้เฉพาะเรื่อง Layout และการมองเห็นตามที่ร้องขอเท่านั้น
17. หากมี Code เดิมที่ผิดพลาดหรือปิด Tag / Syntax ไม่ครบจนทำให้ Layout ทำงานไม่ได้ สามารถแก้เฉพาะส่วนที่จำเป็นให้สมบูรณ์ได้ แต่ห้ามเปลี่ยนพฤติกรรมเดิม
18. ก่อนแก้ไขต้องตรวจสอบความสัมพันธ์ระหว่าง HTML, CSS และ JavaScript ก่อน เพื่อไม่ให้การเปลี่ยนตำแหน่ง Layout ทำให้ JavaScript เดิมเสีย
19. ต้องคง ID เดิมทั้งหมด เพื่อให้ game.js ที่อ้างอิง DOM เดิมยังทำงานได้
20. ห้าม Refactor Code ที่ไม่เกี่ยวข้อง
21. ห้ามปรับปรุงส่วนอื่นนอกเหนือจากงานที่ระบุใน Prompt นี้

# ปัญหาปัจจุบัน

พบปัญหาเฉพาะด้านการมองเห็นและ Responsive Layout โดยเฉพาะ Smartphone ที่เล่นในแนวตั้ง

ปัญหาที่พบคือ

1. Heading แสดงสถานะรอบ เช่น

"ถึงรอบตัวละครสี..."

Screen Reader ยังสามารถพบ Heading ได้ แต่ผู้เล่นที่มองเห็นแจ้งว่า Heading เหมือนหายไปหรือไม่อยู่ในตำแหน่งที่เหมาะสม

2. กองไพ่ที่คว่ำและไพ่ที่เปิดแสดง ไม่สามารถจัด Layout ให้สวยงามและสมดุลบน Smartphone แนวตั้ง

3. ไพ่เปิดมีขนาดใหญ่กว่ากองไพ่คว่ำมากเกินไป ทำให้ Layout ไม่สมดุล

4. บางกรณีกองไพ่และไพ่เปิดจัดเรียงเป็นแนวตั้ง ทั้งที่ต้องการให้เป็นแนวนอน ซ้ายและขวา

5. ปุ่มดูสถานะผู้เล่นทุกคนแบบ Floating Button มีโอกาสบดบังพื้นที่ไพ่ในมือหรือข้อมูลของผู้เล่น

6. ต้องการให้หน้าเล่นเกมบน Smartphone แนวตั้ง แสดงองค์ประกอบสำคัญครบและพอดีกับหน้าจอให้มากที่สุด โดยไม่ต้อง Scroll ระหว่างเล่นเกมในอุปกรณ์ Smartphone ทั่วไป

# เป้าหมาย Layout ใหม่

หน้าเล่นเกมต้องแบ่งเป็น 3 ส่วนหลัก จากบนลงล่าง

## ส่วนที่ 1: Game Header

ด้านบนสุดต้องมี

ฝั่งซ้าย:

Heading แสดงสถานะ Turn ปัจจุบัน เช่น

"ถึงรอบตัวละครสีแดง"

หรือข้อความ Turn เดิมที่ระบบ game.js อัปเดตอยู่แล้ว

ฝั่งขวา:

ปุ่ม Refresh Audio

ต้องอยู่ในแนวเดียวกับ Heading

รูปแบบต้องเป็น

[ Heading แสดง Turn ]                         [ 🔊 ]

ข้อกำหนด:

* Heading ต้องชิดซ้าย
* ปุ่ม Refresh Audio ต้องชิดขวา
* ทั้งสองต้องอยู่ใน Container เดียวกัน
* ต้องใช้ Flex Layout หรือวิธี Responsive ที่เหมาะสม
* Heading ต้องไม่ถูกซ่อน
* Heading ต้องยังเป็น Heading เดิม
* ต้องคง id="title-game"
* ปุ่มต้องคง id="btn-refresh-audio"
* ห้ามเปลี่ยน Logic การอัปเดตข้อความ Heading จาก game.js
* ปุ่ม Refresh ต้องมีขนาดเล็ก แต่ยังเหมาะกับการกดบน Smartphone
* ห้ามให้ปุ่ม Refresh ไปบดบัง Heading

---

## ส่วนที่ 2: พื้นที่กองไพ่และไพ่เปิด

ใต้ Game Header ให้แสดงกองไพ่และไพ่เปิดในแนวนอนเสมอ

รูปแบบ:

[ กองไพ่คว่ำ ]                 [ ไพ่เปิด ]

โดย

ฝั่งซ้าย:

id="deck-info-container"

ฝั่งขวา:

id="table-info-container"

ข้อกำหนดสำคัญ:

1. ทั้งสองต้องอยู่ในแนวนอนบน Smartphone แนวตั้ง
2. ห้ามปล่อยให้ Layout ปกติเปลี่ยนเป็นแนวตั้งโดยไม่จำเป็น
3. ใช้ CSS Grid 2 Columns หรือ Flex Layout ที่บังคับให้เหมาะสม
4. พื้นที่ซ้ายและขวาควรมีความสมดุล
5. ลดขนาดไพ่เปิดลงจากเดิม
6. ปรับขนาดกองไพ่และไพ่เปิดให้ใกล้เคียงกัน
7. ไม่จำเป็นต้องเท่ากันเป๊ะ แต่ต้องดูสมดุลและสวยงาม
8. เหรียญบนไพ่ยังต้องแสดงครบ
9. ห้ามให้เหรียญถูกตัดออกจากหน้าจอ
10. Animation เดิมของไพ่และเหรียญต้องทำงานเหมือนเดิม

ต้องคง ID เดิมทั้งหมด ได้แก่

* deck-info-container
* deck-count
* table-info-container
* table-card-display
* table-coins-display

ห้ามเปลี่ยนชื่อ

## ส่วนที่ 3: สถานะของผู้เล่นเครื่องนี้

ส่วนล่างสุดของหน้าเล่นเกม

ให้แสดงเฉพาะสถานะของผู้เล่นที่กำลังเล่นอยู่บนเครื่องนั้นเท่านั้น

ใช้ Container เดิม:

id="my-status-group"

ต้องแสดงข้อมูลเดิมทั้งหมด เช่น

* ตัวละครของตัวเอง
* เหรียญของตัวเอง
* ไพ่ที่ได้รับ
* ไพ่ในมือ

ให้จัด Layout ให้สวยงาม อ่านง่าย และ Responsive

ข้อสำคัญ:

* ห้ามเปลี่ยนข้อมูล
* ห้ามเปลี่ยน Logic
* ห้ามเปลี่ยน Animation
* ห้ามเปลี่ยนวิธีที่ game.js สร้างข้อมูล

ให้แก้เฉพาะ CSS / Layout เท่านั้นเท่าที่จำเป็น

# ปุ่มดูสถานะผู้เล่นทุกคน

ปุ่ม

id="btn-view-others"

ยังต้องอยู่บริเวณด้านขวาล่าง

แต่ต้องปรับให้

1. มีขนาดเล็กพอเหมาะ
2. ยังกดง่ายบน Smartphone
3. ไม่บดบังไพ่ในมือ
4. ไม่บดบังสถานะผู้เล่น
5. ไม่ทำให้ Layout หลักเสีย

สามารถใช้ Floating Button ต่อได้ แต่ต้องปรับตำแหน่งและขนาดให้ปลอดภัยกับหน้าจอ Smartphone

ควรรองรับ Safe Area ของ iPhone หากจำเป็น

ห้ามเปลี่ยน Function การเปิดดูสถานะผู้เล่นทั้งหมด

# Responsive Requirements

ต้องปรับเฉพาะหน้าเล่นเกมให้ Responsive โดยให้ความสำคัญกับ Smartphone แนวตั้งเป็นอันดับแรก

ต้องรองรับ

* Smartphone Android
* iPhone Safari
* หน้าจอ Smartphone แนวตั้ง
* Tablet
* Desktop

หลักการคือ

Mobile First

และต้องใช้ Responsive CSS ที่เหมาะสม เช่น

* CSS Grid
* Flexbox
* clamp()
* min()
* max()
* Media Queries
* 100dvh เมื่อเหมาะสม
* Safe Area Insets เมื่อเหมาะสม

ห้ามใช้วิธี Fix ขนาดแบบเดียวจนทำให้บาง Smartphone ล้นหน้าจอ

---

# เป้าหมายสำคัญเรื่องพื้นที่หน้าจอ

ระหว่างเล่นเกม ต้องพยายามให้ส่วนสำคัญทั้งหมดแสดงครบภายใน Viewport เดียวบน Smartphone แนวตั้งทั่วไป ได้แก่

1. Heading Turn
2. ปุ่ม Refresh Audio
3. กองไพ่
4. ไพ่เปิด
5. เหรียญบนไพ่
6. ปุ่มควบคุมการเล่นเมื่อถึง Turn ของผู้เล่น
7. สถานะผู้เล่นของตัวเอง
8. ไพ่ในมือ

ต้องลด Padding และ Spacing ที่ไม่จำเป็นเฉพาะบน Mobile

แต่ห้ามลดขนาดจนอ่านข้อความหรือกดปุ่มได้ยาก

หากหน้าจอบางรุ่นมีความสูงต่ำมาก ให้ใช้ Responsive Scaling ที่เหมาะสมตามความสูงหน้าจอ แทนการทำให้ Layout หลักพัง

# Heading ต้องแก้ปัญหา Screen Reader เจอ แต่ผู้มองเห็นเหมือนหาย

ให้ตรวจสอบอย่างละเอียดว่า

* มี CSS ใดซ่อน Heading หรือไม่
* มี Element อื่นทับ Heading หรือไม่
* z-index มีปัญหาหรือไม่
* position absolute/fixed มีปัญหาหรือไม่
* margin/padding ทำให้ Heading ถูกดันออกจากตำแหน่งหรือไม่
* Heading ถูกจัดให้อยู่ในพื้นที่ที่ผู้มองเห็นไม่สังเกตหรือไม่

จากนั้นแก้ปัญหาด้วยการจัด Heading ใหม่ให้อยู่ใน Game Header เดียวกับปุ่ม Refresh Audio

ต้องคง

id="title-game"

และต้องไม่ทำให้ Screen Reader Accessibility เดิมเสีย

# ไฟล์ที่ควรแก้

ให้ตรวจสอบทั้ง 3 ไฟล์ก่อน

* no.html
* style.css
* game.js

แต่ให้แก้เฉพาะไฟล์ที่จำเป็นจริง

คาดหวังว่า:

1. no.html
   ใช้ปรับโครงสร้าง Layout ของหน้าเล่นเกม

2. style.css
   ใช้แก้ Responsive Layout เป็นหลัก

3. game.js
   ห้ามแก้ Logic

ให้แก้ game.js เฉพาะกรณีจำเป็นจริง ๆ จากการย้ายโครงสร้าง DOM และต้องอธิบายอย่างชัดเจนว่าทำไมจึงจำเป็น

หากสามารถคง ID เดิมทั้งหมดได้ ให้ห้ามแก้ game.js

# ข้อกำหนดก่อนส่งงาน

ก่อนส่ง Code ที่แก้ไขแล้ว ให้ตรวจสอบว่า

1. Heading มองเห็นได้จริง
2. Heading อยู่ซ้ายและปุ่ม Refresh อยู่ขวาในแถวเดียวกัน
3. กองไพ่อยู่ซ้าย
4. ไพ่เปิดอยู่ขวา
5. กองไพ่และไพ่เปิดอยู่ในแนวนอนบน Smartphone แนวตั้ง
6. ขนาดของไพ่ทั้งสองฝั่งสมดุลกัน
7. เหรียญบนไพ่ไม่ถูกตัด
8. สถานะผู้เล่นของตัวเองแสดงครบ
9. ไพ่ในมือไม่ถูก Floating Button บดบัง
10. Screen Reader เดิมยังทำงาน
11. Keyboard Shortcut เดิมยังทำงาน
12. ระบบเสียงเดิมยังทำงาน
13. Animation เดิมยังทำงาน
14. Firebase เดิมยังทำงาน
15. Multiplayer เดิมยังทำงาน
16. Turn Logic เดิมยังทำงาน 100%
17. Desktop Layout ไม่เสีย
18. Tablet Layout ไม่เสีย
19. iPhone Safari ไม่เสีย
20. Android Browser ไม่เสีย

# รูปแบบการส่งงาน

ให้แก้ไข Code จริงเฉพาะส่วนที่จำเป็น

ห้ามเขียน Code ใหม่ทั้งระบบ

ห้าม Refactor ส่วนที่ไม่เกี่ยวข้อง

ต้องคง Code เดิมให้มากที่สุด

หลังแก้ไขให้สรุปสั้น ๆ ว่า

1. แก้ไฟล์ใดบ้าง
2. แก้เรื่องใดบ้าง
3. game.js ถูกแก้หรือไม่
4. หากแก้ game.js ต้องระบุเหตุผล
5. ยืนยันว่าไม่ได้เปลี่ยน Logic เกม

เป้าหมายสูงสุดคือ:

"ปรับเฉพาะ Visual Layout ของหน้าเล่นเกม ให้สวยงาม สมดุล Responsive และพอดีกับ Smartphone แนวตั้ง โดยคงการทำงานเดิมทั้งหมด 100% และห้ามแตะต้อง Logic เกมหรือระบบอื่นที่ไม่เกี่ยวข้อง"
