ให้แก้ไขเฉพาะเรื่องเดียวเท่านั้น:

# การแสดงผล Visual ของปลายซ้ายและปลายขวาบนกระดาน

ปัจจุบัน Visual ของปลายกระดานใช้การสร้างโดมิโน่เต็มตัวที่มี 2 ครึ่ง

ทำให้ค่าปลายเดียวกันถูกแสดงซ้ำทั้งบนและล่าง

ตัวอย่าง:

ปลายซ้ายเป็นเลข 5:

เลข 5 และจุดถูกแสดงซ้ำ 2 ครึ่ง

ปลายซ้ายเป็น “หลับ”:

คำว่า “หลับ” ถูกแสดง 2 ครั้ง

นี่คือปัญหาที่ต้องแก้

---

# เป้าหมายที่ต้องการ

ปลายซ้ายและปลายขวาต้องแสดงเฉพาะ:

**ค่าปลายที่ต้องเล่นต่อเพียงค่าเดียว**

เท่านั้น

# ตัวอย่างผลลัพธ์

## ถ้าเป็นตัวเลข

ต้องแสดงจุดของตัวเลขเพียงชุดเดียว

เช่น:

ปลายซ้าย = 5

แสดงจุดของเลข 5 เพียงชุดเดียว

ห้ามสร้างเลข 5 ซ้ำอีกครึ่งหนึ่ง

# แนวทางที่ต้องใช้

## สำคัญมาก

ห้ามแก้ Game State

ห้ามแก้ค่าจริงของ:

* `game.leftEnd`
* `game.rightEnd`

ค่าทั้งสองต้องทำงานเหมือนเดิม 100%

ให้แก้เฉพาะวิธี **Render Visual**

---

## ห้ามใช้วิธีสร้างโดมิโน่เต็มตัวแล้วซ่อนครึ่งหนึ่งแบบเสี่ยง ๆ

ห้ามแก้โดย:

* สร้างโดมิโน่ 2 ครึ่งเหมือนเดิม
* แล้วใช้ CSS ซ่อนครึ่งหนึ่ง
* หรือใช้ overflow ตัดครึ่งแบบชั่วคราว

ต้องสร้าง Visual สำหรับ **ปลายกระดานที่มีค่าเดียว** โดยตรง

---

# สิ่งที่สามารถใช้ของเดิมได้

หากมีฟังก์ชันเดิมสำหรับสร้างจุดตัวเลข เช่นระบบ Pip/Grid

ให้ใช้ระบบเดิมซ้ำเท่าที่เหมาะสม

ห้ามเขียนระบบ Game Logic ใหม่

สามารถสร้างฟังก์ชัน Render เฉพาะสำหรับ End Visual ได้ หากจำเป็น เช่นแนวคิด:

`renderBoardEndVisual(value)`

แต่ชื่อฟังก์ชันสามารถเลือกได้ตามความเหมาะสม

โดยฟังก์ชันนี้ต้องสร้าง Visual ของ:

**1 ค่าเท่านั้น**

# ต้องตรวจสอบก่อนส่งไฟล์

ก่อนส่งกลับ ต้องตรวจสอบว่า:

### ตัวเลข

* ปลายซ้ายแสดงจุดเพียง 1 ชุด
* ปลายขวาแสดงจุดเพียง 1 ชุด
* ไม่มีเลขหรือจุดซ้ำบนและล่าง

### ตัวพิเศษ

* หลับ แสดงเพียงครั้งเดียว
* 2+ แสดงเพียงครั้งเดียว
* 3+ แสดงเพียงครั้งเดียว
* ย้อนศร แสดงเพียงครั้งเดียว

### Logic

* `game.leftEnd` ทำงานเหมือนเดิม
* `game.rightEnd` ทำงานเหมือนเดิม
* การวางซ้ายและขวายังทำงานเหมือนเดิม
* Multiplayer ยังทำงานเหมือนเดิม
* ARIA ยังทำงานเหมือนเดิม

# รูปแบบการตอบกลับ — บังคับสูงสุด

ต้องส่งกลับมาเป็นไฟล์ `domino.js` ฉบับเต็มทั้งหมด

## ห้ามเด็ดขาด

* ห้ามตัดทอนโค้ด
* ห้ามใช้ `...`
* ห้ามส่งเฉพาะ Function ที่แก้
* ห้ามบอกว่า “ส่วนอื่นเหมือนเดิม”
* ห้ามละเว้นโค้ดส่วนใด
* ห้ามสรุปแทนไฟล์

ต้องส่งโค้ดไฟล์ `domino.js` ครบถ้วนสมบูรณ์ตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย

โดยต้องรักษาโค้ดทุกส่วนที่ไม่เกี่ยวข้องไว้เหมือนต้นฉบับ
