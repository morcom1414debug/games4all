คุณได้รับไฟล์ `style.css` ของเกม DOMINO

ให้แก้ไขเฉพาะเรื่อง **Visual Layout ของส่วนปลายกระดานและกองจั่ว** ตามรายละเอียดนี้เท่านั้น

# เป้าหมาย

ส่วนกลางของเกมต้องแสดงในแนวระนาบจากซ้ายไปขวาเป็น:

**ปลายซ้าย → กองจั่ว → ปลายขวา**

และต้องรองรับ Visual รูปแบบใหม่ของปลายกระดาน ซึ่งจะไม่แสดงโดมิโน่เต็มตัว 2 ครึ่งอีกต่อไป

ปลายซ้ายและปลายขวาต้องถูกออกแบบให้รองรับการแสดง:

**ค่าเดียวเท่านั้น**

เช่น:

* เลขและจุดเพียงชุดเดียว
* หลับ เพียงครั้งเดียว
* 2+ เพียงครั้งเดียว
* 3+ เพียงครั้งเดียว
* ย้อนศร เพียงครั้งเดียว

---

# สิ่งที่ต้องแก้

## 1. Middle Layout

ปรับ CSS ที่เกี่ยวข้องกับ `.middle-area` และองค์ประกอบที่เกี่ยวข้องเท่าที่จำเป็น

เพื่อให้ Visual แสดงตามลำดับ:

**ซ้าย → กองจั่ว → ขวา**

โดยต้องจัดให้:

* สมดุล
* มองเห็นชัดเจน
* ไม่ซ้อนกัน
* Responsive
* ใช้งานได้ดีบนมือถือแนวตั้ง
* ใช้งานได้ดีบน Desktop

---

## 2. Board End Visual ใหม่

ต้องรองรับ Visual สำหรับปลายกระดานที่มีเพียงค่าเดียว

Visual นี้ต้อง:

* ไม่มีการแบ่งครึ่งบนและล่าง
* ไม่มีเส้นแบ่งกลาง
* ไม่มีพื้นที่สำหรับค่าที่สอง
* แสดงจุดตัวเลขเพียงชุดเดียว
* แสดงข้อความ Special เพียงครั้งเดียว
* จัดเนื้อหาไว้ตรงกลางอย่างสวยงาม

ตัวอย่าง:

เลข:

[ จุดของเลขเพียง 1 ชุด ]

Special:

[ หลับ เพียง 1 ครั้ง ]

---

## 3. ป้ายชื่อด้านล่าง

ต้องคงป้ายชื่อ:

* `ซ้าย`
* `ขวา`

ไว้ด้านล่างของ Visual ปลายกระดาน

ต้องจัดให้:

* ไม่ซ้อนกับตัวโดมิโน่
* ไม่เหลื่อมกัน
* มีระยะห่างเหมาะสม
* อ่านง่าย
* อยู่ตรงกลางใต้ Visual

---

# ปัญหาที่ต้องป้องกัน

CSS ใหม่ต้องไม่ทำให้เกิดปัญหา:

* ข้อความ “หลับ” ซ้อนกัน
* ข้อความ Special ซ้ำ
* จุดเลขซ้ำบนและล่าง
* เส้นแบ่งกลางของโดมิโน่เดิม
* ป้าย ซ้าย/ขวา ซ้อนกับ Visual
* Responsive บนมือถือเสีย
* Layout ล้นหน้าจอ
* Horizontal overflow

# กฎเหล็กสูงสุด — ห้ามละเมิดเด็ดขาด

## ห้ามแก้ CSS ที่ไม่เกี่ยวข้อง

ห้ามเปลี่ยน Visual ส่วนอื่น เช่น:

* หน้า Login
* หน้าหลัก
* Lobby
* ผู้เล่น
* Bot
* Status Bar
* Current Turn
* การ์ด/โดมิโน่ในมือ
* ปุ่ม
* Modal
* Result Screen
* Animation
* เอฟเฟกต์อื่น
* สี Theme โดยรวม

เว้นแต่มี CSS rule ที่จำเป็นต้องปรับโดยตรงเพื่อให้ Layout ปลายซ้าย → กองจั่ว → ปลายขวาทำงานเท่านั้น

---

## ห้ามเปลี่ยนกติกาหรือ Logic

CSS นี้ต้องเป็นการปรับเฉพาะ Visual เท่านั้น

ห้ามกระทบ:

* Game Logic
* Turn System
* Draw System
* Special Domino
* Double Domino
* DOMINO! System
* Firebase
* Peer.js
* Audio
* ARIA
* Accessibility
* Focus

---

## ห้าม Refactor CSS ทั้งไฟล์

ห้าม:

* เขียน CSS ใหม่ทั้งไฟล์
* ลบ CSS เดิมที่ไม่เกี่ยวข้อง
* จัดเรียง CSS ใหม่ทั้งไฟล์
* เปลี่ยนชื่อ Class ที่มีอยู่โดยไม่จำเป็น
* เปลี่ยน Theme
* เปลี่ยนสีส่วนอื่นเอง

ให้แก้หรือเพิ่มเฉพาะ CSS ที่จำเป็นต่อภารกิจนี้

---

## ต้องรองรับ HTML และ JavaScript เดิม

CSS ที่แก้ต้องไม่ทำให้:

* ID เดิมเสีย
* Class เดิมเสีย
* Animation เดิมเสีย
* JavaScript เดิมหา Element ไม่เจอ

---

# รูปแบบการตอบกลับ — บังคับ

ต้องส่งกลับมาเป็นไฟล์ `style.css` ฉบับเต็มทั้งหมด

ห้ามเด็ดขาด:

* ห้ามตัดทอน
* ห้ามใช้ `...`
* ห้ามส่งเฉพาะ CSS ที่แก้
* ห้ามบอกว่าส่วนอื่นเหมือนเดิม
* ห้ามละเว้นส่วนใดของไฟล์

ต้องส่งไฟล์ CSS ฉบับเต็มครบถ้วนสมบูรณ์ 100%
