คุณได้รับไฟล์ `domino.html` ของเกม DOMINO

ให้แก้ไขไฟล์นี้เฉพาะเรื่อง **การจัดลำดับตำแหน่งการแสดงผล Visual ของส่วนกลางในหน้าจอเกม** ตามรายละเอียดด้านล่างเท่านั้น

# เป้าหมายที่ต้องแก้

ปัจจุบันในส่วนกลางของเกม มีองค์ประกอบที่เกี่ยวข้องกับการแสดงผลดังนี้:

* กองจั่ว
* ปลายซ้าย
* ปลายขวา

ให้ปรับลำดับการแสดงผลในแนวระนาบจากซ้ายไปขวาใหม่เป็น:

**ปลายซ้าย → กองจั่ว → ปลายขวา**

ผลลัพธ์ที่ผู้เล่นมองเห็นต้องสื่อความหมายอย่างชัดเจนว่า:

**[ ปลายซ้าย ] [ กองจั่ว ] [ ปลายขวา ]**

โดยต้องเป็นการจัดลำดับตำแหน่ง Visual เท่านั้น

---

# สิ่งที่ต้องทำ

ให้ตรวจสอบเฉพาะส่วน `.middle-area` และโครงสร้าง HTML ที่เกี่ยวข้องกับองค์ประกอบต่อไปนี้:

* `board-left-container`
* `ui-deck-pile`
* `board-right-container`

ให้จัดลำดับการแสดงผลใหม่ตามนี้:

1. `board-left-container`
2. `ui-deck-pile`
3. `board-right-container`

โดยต้องคง ID เดิมทั้งหมดไว้เหมือนเดิม

---

# กฎเหล็กสูงสุด — ห้ามละเมิดเด็ดขาด

## 1. ห้ามเปลี่ยนชื่อ ID เด็ดขาด

ต้องคง ID ต่อไปนี้ไว้เหมือนเดิมทุกตัว:

* `board-left-container`
* `board-right-container`
* `ui-deck-pile`
* `deck-count-visual`
* `board-left-aria`
* `board-right-aria`
* `deck-aria-label`

ห้ามเปลี่ยนชื่อ ห้ามลบ ห้ามสร้างชื่อใหม่เพื่อแทนที่

---

## 2. แก้เฉพาะโครงสร้าง Visual ที่จำเป็นเท่านั้น

ห้ามแก้ไขสิ่งต่อไปนี้เด็ดขาด:

* Game Logic
* JavaScript
* Firebase
* Peer.js
* ระบบ Host
* ระบบ Client
* ระบบห้อง
* ระบบผู้เล่น
* ระบบ Bot
* Turn System
* กฎการเล่น
* ระบบจั่ว
* DOMINO! Logic
* Double Domino Logic
* Special Domino Logic
* ระบบเสียง
* Audio
* ARIA Live
* Accessibility Logic
* Keyboard Control
* Focus Management
* Modal
* Animation
* ส่วนอื่นของหน้า HTML ที่ไม่เกี่ยวข้องกับการเรียงตำแหน่ง Visual นี้

---

## 3. ห้ามเปลี่ยนข้อความหรือ Accessibility เอง

ห้ามเปลี่ยน:

* aria-label
* aria-live
* role
* sr-only
* ข้อความสำหรับ Screen Reader

เว้นแต่จำเป็นอย่างหลีกเลี่ยงไม่ได้จากการย้ายตำแหน่ง HTML เท่านั้น

แต่โดยหลักต้องพยายามคงทุกอย่างเหมือนเดิม 100%

---

## 4. ห้าม Refactor

ห้ามทำสิ่งต่อไปนี้:

* Refactor โค้ด
* จัดระเบียบโค้ดใหม่
* เปลี่ยนรูปแบบโค้ดทั้งไฟล์
* ลบ comment
* ย้ายส่วนอื่นที่ไม่เกี่ยวข้อง
* เปลี่ยน indentation ของทั้งไฟล์โดยไม่จำเป็น
* ปรับปรุงโค้ดอื่นเอง
* แก้ Bug อื่นเอง
* เพิ่ม Feature ใหม่เอง

ให้แก้เฉพาะสิ่งที่ร้องขอเท่านั้น

---

## 5. ต้องรักษาการทำงานร่วมกับ JavaScript เดิม 100%

HTML หลังแก้ต้องยังสามารถทำงานร่วมกับ `domino.js` เดิมได้

ห้ามทำให้ JavaScript ที่อ้างอิง Element ด้วย ID เดิมเสีย

ห้ามเปลี่ยน ID

ห้ามเปลี่ยนความหมายของ Element

---

# ผลลัพธ์ที่ต้องการ

หลังแก้ ผู้เล่นที่มองเห็นต้องเห็นส่วนกลางเรียงจากซ้ายไปขวาเป็น:

**ปลายซ้าย → กองจั่ว → ปลายขวา**

และส่วนอื่นทั้งหมดของเกมต้องเหมือนเดิม

---

# รูปแบบการตอบกลับ — บังคับ

ต้องส่งกลับมาเป็นไฟล์ `domino(10).html` ฉบับเต็มทั้งหมด

## ห้ามเด็ดขาด

* ห้ามตัดทอนโค้ด
* ห้ามใช้ `...`
* ห้ามใช้คำว่า “ส่วนอื่นเหมือนเดิม”
* ห้ามส่งเฉพาะส่วนที่แก้
* ห้ามสรุปแทนไฟล์
* ห้ามละเว้นแม้แต่บรรทัดเดียว

ต้องส่งโค้ดไฟล์ฉบับเต็มตั้งแต่:

`<!DOCTYPE html>`

จนถึง:

`</html>`

ครบถ้วนสมบูรณ์ 100%
