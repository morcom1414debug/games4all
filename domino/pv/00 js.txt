งานนี้ให้แก้ไขเฉพาะไฟล์ JavaScript ที่ส่งให้เท่านั้น และแก้ไขเฉพาะปัญหาเรื่องการแสดง Visual ของปลายโดมิโน่บนกระดานเท่านั้น

# เป้าหมายที่ต้องทำให้สำเร็จ

ปัจจุบันปลายซ้ายและปลายขวาของกระดานแสดงเป็นโดมิโน่เต็มตัว 2 ฝั่ง ทำให้เห็นจุดซ้ำทั้งด้านบนและด้านล่าง

ต้องแก้ให้ปลายกระดานเป็นดังนี้อย่างเด็ดขาด:

* ปลายซ้าย แสดงเฉพาะค่า `leftEnd` เพียงค่าเดียว
* ปลายขวา แสดงเฉพาะค่า `rightEnd` เพียงค่าเดียว
* แต่ละปลายต้องเป็นโดมิโน่เพียง "หน้าเดียว"
* ห้ามมีครึ่งที่สอง
* ห้าม render ค่าเดิมซ้ำเป็น 2 ฝั่ง
* ห้ามสร้าง pseudo tile แบบ `left: val, right: val`
* ห้ามใช้ `renderTileHTML()` สำหรับ Visual ปลายกระดาน หากฟังก์ชันนั้นสร้างโดมิโน่เต็มตัว 2 halves
* ต้องสร้าง Visual ของปลายกระดานด้วยโครงสร้างเฉพาะสำหรับ End Tile

# รูปแบบ Visual ที่ต้องได้

ปลายซ้ายและปลายขวาต้อง:

* เป็นพื้นสีดำ
* จุดโดมิโน่เป็นสีขาว
* ใช้รูปแบบการจัดจุดแบบโดมิโน่มาตรฐาน
* รูปแบบจุดต้องเป็นระบบเดียวกับโดมิโน่ในมือ
* แสดงเพียงค่าเดียวต่อหนึ่งปลาย
* ห้ามมีจุดซ้ำด้านบนและด้านล่าง
* ห้ามมี 2 หน้า
* ห้ามมีเส้นแบ่งกลางของโดมิโน่เต็มตัว

ตัวอย่างแนวคิด:

ปลายซ้าย = ค่า 5

ต้องเห็นเพียงหน้าเดียวที่มีจุด 5 จุด

ปลายขวา = ค่า 3

ต้องเห็นเพียงหน้าเดียวที่มีจุด 3 จุด

ห้ามทำให้กลายเป็น:

5 | 5

หรือ

3 | 3

ไม่ว่าจะในแนวตั้งหรือแนวนอน

# แนวทางการแก้ไขที่บังคับ

ให้ตรวจสอบส่วน Render Board Ends โดยละเอียด

ต้องเปลี่ยนระบบการสร้าง Visual ปลายกระดานให้:

1. สร้าง element สำหรับปลายกระดานโดยเฉพาะ เช่น class:

`domino-end-tile`

2. element นี้ต้องรับค่าเพียงค่าเดียว

3. สำหรับตัวเลขปกติ ให้ใช้ระบบสร้างจุดโดมิโน่มาตรฐานที่มีอยู่แล้ว เช่น `getPipLayoutHTML(val)` หากเป็นระบบที่ใช้สร้างจุดเดียวกับโดมิโน่ในมือ

4. ต้องไม่เรียกระบบที่สร้าง:

* `tile.left`
* `tile.right`

พร้อมกันสำหรับปลายกระดาน

5. ต้องไม่สร้าง Full Domino เพื่อเอามาใช้แทน Half/Single End

6. การแสดงปลายซ้ายและปลายขวาต้องเป็นคนละ element และแต่ละ element มีค่าเดียวเท่านั้น

# เงื่อนไขสำคัญที่สุด

ต้องแก้ให้สาเหตุเดิมหายจริง:

เดิมระบบสร้างปลายกระดานจาก Full Tile ที่มีค่า:

`left: val`

และ

`right: val`

จึงทำให้ Render ออกมาเป็น 2 halves

หลังแก้:

ปลายกระดานต้องไม่มีโครงสร้าง Full Tile อยู่เลย

หนึ่งปลาย = หนึ่งค่า = หนึ่งหน้า = หนึ่งชุดจุด

เท่านั้น

# การส่งไฟล์กลับ — กฎเหล็กสูงสุด

เมื่อแก้ไขเสร็จ:

1. ต้องส่งกลับมาเป็นไฟล์ JavaScript ฉบับเต็มทั้งหมด
2. ต้องครบตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย
3. ห้ามตัดทอน
4. ห้ามใช้ `...`
5. ห้ามส่งเฉพาะส่วนที่แก้
6. ห้ามส่ง Diff
7. ห้ามส่ง Patch
8. ห้ามส่งตัวอย่างโค้ดแทนไฟล์จริง
9. ต้องคงโค้ดทุกส่วนที่ไม่ได้รับอนุญาตให้แก้ไว้เหมือนต้นฉบับ
10. ส่งเป็นไฟล์เต็มเพียงไฟล์เดียวที่พร้อมนำไปแทนไฟล์เดิมได้ทันที

ก่อนส่งกลับ ต้องตรวจสอบด้วยตัวเองว่า:

* ปลายซ้ายมีเพียง 1 หน้า
* ปลายขวามีเพียง 1 หน้า
* ไม่มีการ render ซ้ำ 2 halves
* ไม่มี `left: val, right: val` เพื่อสร้าง Visual ปลายกระดาน
* จุดเป็นรูปแบบโดมิโน่มาตรฐาน
* Game Logic เดิมไม่ได้เปลี่ยนแม้แต่น้อย

ให้เริ่มแก้เฉพาะไฟล์ JavaScript ที่ส่งให้ และส่งไฟล์ฉบับเต็มกลับมาเท่านั้น
