# เป้าหมาย

หลังจาก JavaScript ถูกแก้ให้สร้างปลายกระดานด้วย class เฉพาะ เช่น:

`domino-end-tile`

ให้สร้างหรือปรับ CSS เฉพาะสำหรับ Visual นี้

ปลายโดมิโน่บนกระดานต้องแสดงเป็น:

* โดมิโน่หน้าเดียว
* พื้นหลังสีดำ
* จุดสีขาว
* จุดจัดวางแบบโดมิโน่มาตรฐาน
* ไม่มีครึ่งบน/ล่างซ้ำ
* ไม่มีครึ่งซ้าย/ขวาซ้ำ
* ไม่มีเส้นแบ่งกลาง
* ไม่มีลักษณะของโดมิโน่เต็มตัว 2 halves

# กฎสำคัญที่สุด

`.domino-end-tile` ต้องเป็น Visual คนละประเภทจาก `.domino-tile`

ห้ามให้ `.domino-end-tile` รับโครงสร้าง Full Domino ที่ทำให้เกิด:

* 2 halves
* เส้นแบ่งกลาง
* Grid สำหรับ 2 หน้า
* pseudo full tile
* การแบ่งพื้นที่สำหรับ `left` และ `right`

เด็ดขาด

# สีที่บังคับ

Visual ปลายกระดาน:

* Background: สีดำ
* Pip/Dot: สีขาว

ต้องมี Contrast ชัดเจน

ห้ามเปลี่ยนสีของโดมิโน่ในมือ

ห้ามเปลี่ยน Theme ของเกม

ห้ามเปลี่ยนสี UI ส่วนอื่น

# กฎเหล็กสูงสุด

## 1. แก้เฉพาะ CSS ที่เกี่ยวข้องโดยตรง

แก้ได้เฉพาะ:

* CSS ของ `.domino-end-tile`
* CSS ที่จำเป็นโดยตรงสำหรับให้ End Tile แสดงเป็นหน้าเดียว
* CSS ที่จำเป็นโดยตรงสำหรับสีดำและจุดสีขาวของ End Tile

## 2. ห้ามเปลี่ยน `.domino-tile` เดิมโดยไม่จำเป็น

`.domino-tile` ใช้กับโดมิโน่เต็มตัวในมือและส่วนอื่นของเกม

ห้ามแก้จนทำให้:

* โดมิโน่ในมือเปลี่ยนรูป
* โดมิโน่ในมือเหลือหน้าเดียว
* จุดโดมิโน่ในมือเปลี่ยน
* Animation เดิมเสีย
* Layout เดิมเสีย

## 3. ต้องแยก End Tile ออกจาก Full Tile อย่างเด็ดขาด

ห้ามใช้ CSS แบบที่ทำให้ `.domino-end-tile` ต้องพึ่ง `.domino-tile`

End Tile ต้องสามารถแสดงหน้าเดียวได้อย่างอิสระ

## 4. ห้ามแก้ UI อื่น

ห้ามแก้:

* Layout เกม
* มือผู้เล่น
* กองจั่ว
* ปุ่ม
* Modal
* Status Bar
* Character
* Animation อื่น
* Responsive Layout อื่น

## 5. ห้ามปรับแต่งเอง

ห้าม:

* Refactor CSS ส่วนอื่น
* ลบ CSS ที่ไม่เกี่ยวข้อง
* เปลี่ยนชื่อ class เดิมที่ไม่เกี่ยวข้อง
* ปรับสี Theme
* Optimize ส่วนอื่นเอง

# ผลลัพธ์ที่ต้องตรวจสอบก่อนส่ง

ต้องตรวจสอบให้แน่ใจว่า:

✓ ปลายซ้ายแสดงหน้าเดียว

✓ ปลายขวาแสดงหน้าเดียว

✓ ไม่มีจุดซ้ำ 2 ชุด

✓ ไม่มีเส้นแบ่งกลาง

✓ พื้นสีดำ

✓ จุดสีขาว

✓ รูปแบบจุดเหมือนระบบโดมิโน่มาตรฐานเดียวกับในมือ

✓ `.domino-tile` เดิมยังทำงานเหมือนเดิม

✓ UI อื่นไม่เปลี่ยน

# การส่งไฟล์กลับ — กฎเหล็กสูงสุด

หลังแก้ไขเสร็จ ต้องส่งกลับมาเป็นไฟล์ CSS ฉบับเต็มทั้งหมด

ข้อห้ามเด็ดขาด:

* ห้ามตัดทอน
* ห้ามใช้ `...`
* ห้ามส่งเฉพาะ CSS ที่แก้
* ห้ามส่ง Diff
* ห้ามส่ง Patch
* ห้ามลบส่วนอื่นของไฟล์
* ห้ามสรุปแทนไฟล์

ต้องส่ง:

ไฟล์ CSS เต็ม 100%

ตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย

โดยทุกส่วนที่ไม่เกี่ยวข้องต้องคงเดิมเหมือนต้นฉบับทุกประการ

ให้แก้เฉพาะเรื่อง Visual ของปลายโดมิโน่ให้เป็นหน้าเดียว พื้นดำ จุดขาว และส่งไฟล์ CSS ฉบับเต็มกลับมาเท่านั้น
