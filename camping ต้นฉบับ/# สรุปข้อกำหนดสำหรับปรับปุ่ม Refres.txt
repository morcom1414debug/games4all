# สรุปข้อกำหนดสำหรับปรับปุ่ม Refresh Audio ในเกม Adventure 80

เอกสารนี้รวบรวมสิ่งที่ต้องดำเนินการตามที่สรุปไว้ก่อนหน้า เพื่อใช้เก็บเป็นข้อกำหนดสำหรับแก้ไขไฟล์เกม โดยเน้นให้ปรับเฉพาะระบบปุ่ม Refresh Audio และไม่กระทบการทำงานส่วนอื่นของเกม

## 1. วัตถุประสงค์

เพิ่มปุ่มสำหรับ Refresh หรือปลุกระบบเสียงของเกมให้กลับมาทำงานตามปกติ ในกรณีที่เสียงหยุดทำงานหรือ Web Audio API มีปัญหา เช่น หลังมีสายโทรเข้าใน iOS แม้เกมส่วนอื่นจะยังเล่นต่อได้ตามปกติ


## 2. ข้อกำหนดของปุ่ม

* แสดงเป็น emoji รูปลำโพง สำหรับผู้เล่นที่มองเห็นหน้าจอ

* เป็นปุ่มขนาดเล็ก ไม่เด่นหรือใหญ่จนรบกวนพื้นที่เล่นเกม

* วางไว้ที่ มุมบนขวาสุด ระหว่างเล่นเกม

* ต้องไม่บดบังชื่อหรือสถานะ Turn

* กำหนด `aria-label="Refresh audio"` เพื่อให้ Screen Reader อ่านชื่อปุ่มตามที่กำหนด

* ใช้สีและรูปแบบที่มีความเปรียบต่าง (contrast) ดี มองเห็นปุ่มได้ชัดเจน

## 3. การทำงานเมื่อกดปุ่ม

เมื่อผู้เล่นกดปุ่ม ต้องดำเนินการดังนี้

1. Refresh หรือกู้คืนระบบเสียงของเกม เพื่อให้การเล่นเสียงกลับมาทำงานได้ตามปกติ

2. การกู้คืนต้องครอบคลุมระบบเสียงที่เกมใช้อยู่ ไม่ใช่เพียงเปลี่ยนรูปลักษณ์ของปุ่มหรือแสดงข้อความว่าทำงานแล้ว

3. เมื่อดำเนินการสำเร็จจริง ให้ประกาศข้อความ `Refresh สำเร็จ` ผ่าน ARIA live

4. ต้องไม่ประกาศว่าสำเร็จก่อนที่การดำเนินการจะสำเร็จจริง

5. หลังประกาศแล้ว ต้องจัดการข้อความใน ARIA live ให้สะอาดเรียบร้อย เพื่อไม่ให้ข้อความเดิมค้างหรือรบกวนการประกาศครั้งต่อไป

## 5. ไฟล์ที่ต้องตรวจสอบและปรับแก้

ต้องพิจารณาไฟล์ทั้ง 3 ส่วนให้สัมพันธ์กัน โดยแก้เฉพาะจุดที่จำเป็นต่อฟังก์ชันนี้

### 5.1 HTML

* เพิ่มปุ่มลำโพงในตำแหน่งที่เหมาะสม หากไฟล์ยังไม่มีปุ่มดังกล่าว

* กำหนดชื่อสำหรับ Screen Reader เป็น `aria-label="Refresh audio"`

* ตรวจสอบว่ามี ARIA live region ที่เหมาะสมสำหรับประกาศ `Refresh สำเร็จ` หรือไม่

* ห้ามสร้างองค์ประกอบซ้ำ หากมีองค์ประกอบที่ใช้งานได้อยู่แล้ว

### 5.2 CSS

* กำหนดให้ปุ่มมีขนาดเล็กและอยู่มุมบนขวาสุดระหว่างเล่นเกม

* จัดรูปแบบ emoji ลำโพงให้มองเห็นได้ชัดเจน

* เลือกสีและ contrast ที่เหมาะสม

* ตรวจสอบไม่ให้ปุ่มทับชื่อ Turn หรือองค์ประกอบสำคัญของเกม

* จัดการการแสดงและซ่อนให้สอดคล้องกับสถานะเกม โดยไม่กระทบ layout เดิมเกินความจำเป็น

### 5.3 JavaScript

* เชื่อมการกดปุ่มเข้ากับกระบวนการ Refresh หรือกู้คืนระบบเสียงจริงของเกม

* ใช้ระบบเสียงและโครงสร้างเดิมของเกมเป็นหลัก

* ประกาศ `Refresh สำเร็จ` ผ่าน ARIA live เฉพาะเมื่อการ Refresh สำเร็จจริง

* จัดการการล้างข้อความ ARIA live หลังประกาศให้เรียบร้อย

* ควบคุมการแสดงและซ่อนปุ่มตามสถานะเกม ได้แก่ หน้าแรก, Lobby, ระหว่างเล่น และหน้าจบเกม

* ระวังไม่ให้การ Refresh ทำให้เสียงเดิม ระบบคิวเสียง หรือการเล่นเกมส่วนอื่นทำงานผิดปกติ

## 6. ข้อกำหนดที่ต้องรักษาไว้

การแก้ไขต้องไม่ทำให้สิ่งต่อไปนี้เปลี่ยนแปลงโดยไม่จำเป็น

* ระบบเสียงเดิมและวิธีเรียกเสียงของเกม

* ระบบคิวเสียงและลำดับการประกาศ

* ระบบ ARIA live และข้อความสำหรับ Screen Reader ที่มีอยู่เดิม

* ระบบ Turn และกลไกการเล่นเกม

* การทำงานของหน้าแรก Lobby และหน้าจบเกม

* รูปแบบ responsive และการจัดวางส่วนอื่นของเกม

* ระบบการเข้าถึงด้วย NVDA, JAWS และ VoiceOver


## 7. กฎเหล็กในการแก้ไข

1. แก้เฉพาะเรื่องปุ่ม Refresh Audio เท่านั้น ห้ามขยายขอบเขตไปแก้ปัญหาอื่นที่ไม่ได้ร้องขอ

2. ห้ามเปลี่ยนแปลง logic, ระบบเสียง, ARIA, accessibility, animation, timing, CSS หรือ UI ส่วนอื่น เว้นแต่จำเป็นโดยตรงต่อฟังก์ชันนี้

3. ต้องตรวจสอบไฟล์ต้นฉบับรุ่นล่าสุดก่อนลงมือแก้ไข ห้ามอาศัยการคาดเดาจากชื่อไฟล์หรือโค้ดบางส่วน

4. หากมีระบบหรือองค์ประกอบที่ใช้งานได้อยู่แล้ว ให้ใช้ของเดิมและปรับเฉพาะจุดที่จำเป็น ห้ามสร้างซ้ำโดยไม่จำเป็น

5. ห้ามลบ ย่อ ตัดทอน หรือเขียนทับโค้ดเดิมที่ไม่เกี่ยวข้อง

6. ห้ามเติมฟังก์ชันหรือพฤติกรรมอื่นเองนอกเหนือจากข้อกำหนดที่ระบุไว้

7. ต้องส่งไฟล์ที่แก้ไขกลับมาเป็น ไฟล์เต็มทุกไฟล์ที่มีการเปลี่ยนแปลง พร้อมใช้งานจริง ห้ามใช้ `...`, placeholder หรือส่งเฉพาะ snippet

8. หากแก้ไขเพียงบางไฟล์ ให้ส่งไฟล์เต็มเฉพาะไฟล์ที่แก้ไข และระบุไฟล์ที่ไม่ได้แก้ไขให้ชัดเจน

9. ต้องรักษาชื่อไฟล์และโครงสร้างการเรียกใช้งานเดิม เว้นแต่มีเหตุจำเป็นโดยตรงและได้รับอนุญาต

10. ห้ามกล่าวอ้างว่าทดสอบผ่าน หากไม่ได้ทดสอบจริง และต้องแจ้งข้อจำกัดที่ยังไม่ได้ตรวจสอบอย่างตรงไปตรงมา

## 8. เกณฑ์ตรวจรับงาน

รายการตรวจสอบก่อนส่งงาน

ปุ่มเป็น emoji ลำโพง และมี aria-label เป็น Refresh audio

ปุ่มมีขนาดเล็ก อยู่มุมบนขวาสุด และไม่บดบังชื่อ Turn

ปุ่มแสดงเฉพาะระหว่างเล่นเกม และซ่อนในหน้าแรก Lobby และหน้าจบเกม

เมื่อกดปุ่ม ระบบเสียงได้รับการ Refresh จริง

ประกาศ Refresh สำเร็จ ผ่าน ARIA live เฉพาะเมื่อสำเร็จจริง

ข้อความ ARIA live ได้รับการล้างอย่างเหมาะสมหลังประกาศ

ไม่มีการเปลี่ยนแปลงระบบเสียง ระบบเกม หรือ accessibility ส่วนอื่นโดยไม่จำเป็น

ส่งไฟล์เต็มทุกไฟล์ที่แก้ไข ไม่มีการตัดทอนหรือ placeholder

ตรวจแล้ว 0 จาก 8 ข้อ

ยังตรวจไม่ครบ

สรุป: งานนี้คือเพิ่มปุ่ม Refresh Audio สำหรับกู้คืนระบบเสียงใน Adventure 80 โดยต้องแสดงเฉพาะระหว่างเล่นเกม กู้คืนเสียงได้จริง ประกาศผลผ่าน ARIA live อย่างถูกต้อง และรักษาระบบเดิมทั้งหมดตามกฎเหล็กอย่างเคร่งครัด
